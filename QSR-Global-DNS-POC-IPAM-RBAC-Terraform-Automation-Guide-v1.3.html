3. BlueCat Micetro – REST API & Terraform Examples
Authentication (Bearer token from /login – store in secret manager)
curl -X POST "https://micetro-central.corp.pri/mmws/api/v2/login" -d '{"username":"api-user@corp.root","password":"••••"}'
Create A Record 
curl -X POST "https://micetro-central.corp.pri/mmws/api/v2/dnsRecords" -H "Authorization: Bearer <token>" -d '{"zone":"corp.pri.","name":"app-test","type":"A","rdata":"192.168.30.50","ttl":300}'
Create TXT Record 
curl -X POST "https://micetro-central.corp.pri/mmws/api/v2/dnsRecords" -H "Authorization: Bearer <token>" -d '{"zone":"corp.pri.","name":"_acme-challenge.app-test","type":"TXT","rdata":"\"validation-token-123\"","ttl":60}'
Update Record 
curl -X PUT "https://micetro-central.corp.pri/mmws/api/v2/dnsRecords/<record-id>" -H "Authorization: Bearer <token>" -d '{"rdata":"192.168.30.51"}'
Retrieve Record 
curl -X GET "https://micetro-central.corp.pri/mmws/api/v2/dnsRecords?zone=corp.pri.&name=app-test&type=A" -H "Authorization: Bearer <token>"
Terraform Example (bluecatlabs/bluecat provider) 
resource "bluecat_dns_record" "workstation_a" {
  zone  = "mkt.cloud."
  name  = "ws-market-01"
  type  = "A"
  rdata = "192.168.30.50"
  ttl   = 300
}
4. EfficientIP SOLIDserver – REST API & Terraform Examples
Authentication (X-API-Key)
curl -H "X-API-Key: <your-api-key>" ...
Create A Record 
curl -X POST "https://solidserver.corp.pri/rest/api/v2.0/dns/record/" -H "X-API-Key: <key>" -d '{"zone":"corp.pri","name":"app-test","type":"A","rdata":"192.168.30.50","ttl":300}'
Create TXT Record 
curl -X POST "https://solidserver.corp.pri/rest/api/v2.0/dns/record/" -H "X-API-Key: <key>" -d '{"zone":"corp.pri","name":"_acme-challenge.app-test","type":"TXT","rdata":"validation-token-123","ttl":60}'
Update / Retrieve Records – identical pattern with PUT/GET on /dns/record/<id> or query params. Terraform Example (EfficientIP-Labs/solidserver provider) 
resource "solidserver_dns_record" "workstation_a" {
  zone  = "mkt.cloud"
  name  = "ws-market-01"
  type  = "A"
  rdata = "192.168.30.50"
  ttl   = 300
}
5. Secure API Token Management
Use cloud-native secret managers for short-lived, audited tokens. Azure Key Vault, AWS Secrets Manager, GCP Secret Manager or HashiCorp Vault (dynamic secrets). Terraform example (Azure Key Vault): 
data "azurerm_key_vault_secret" "micetro_token" {
  name         = "micetro-api-token"
  key_vault_id = var.key_vault_id
}
Pipeline best practice: OIDC federation – no static secrets in code. Rotate every 90 days with audit logging.
6. Terraform DNS Modules Overview
Official providers:
• BlueCat: bluecatlabs/bluecat – DNS zones, records, IPAM
• EfficientIP: EfficientIP-Labs/solidserver – DNS records, IPAM
Both support full CRUD and integrate with the service accounts above. Use in CI/CD pipelines under the Terraform / Azure DevOps accounts.
