CSV Column Schema & Import Instructions QSR_Global_DNS_Records_v1_1.csv
Column Definitions
Zone Authoritative zone name (e.g., us.mkt.root, mcd.co.uk)
Name Relative owner name within zone. @ = zone apex
TTL Time-to-live in seconds. 60 = anycast/POS, 300 = stable, 10 = cache-flush test
Type Record type: A · AAAA · CNAME · MX · NS · PTR · SOA · SRV · TXT
RData Record data in standard presentation format (RFC 1035)
Entity CORP-GLOBAL · CORP-REGIONAL · CORP-INFRA · CORP-POC · MARKET-NA/EU/APAC/LATAM/MENA
Market Country/market name or "Global" for CORP records
Region NA · EU · APAC · LATAM · MENA · Global
CloudPrimary AWS · Azure · GCP · All (multi-cloud) · INFRA
Note Human-readable description. Test case references (TC-xx) for POC zone records
Target Platform Import Notes
BlueCat Micetro Filter on Zone column. Import via Micetro CSV import wizard. Use Entity to assign RBAC views. SOA records configure zone properties separately.
AWS Route 53 Filter to ccTLD zones (e.g., mcd.com.au). Create hosted zone, then import as record set. Map Name+.+Zone for FQDN. Exclude SOA/NS (Route 53 manages these).
Azure DNS Use az network dns record-set CLI or Azure DNS import tool. Filter by Region=EU and ccTLD zone names. Azure manages SOA/NS automatically.
Google Cloud DNS Convert to BIND zone file format using gcloud dns record-sets import. Filter APAC ccTLD zones. Exclude SOA/NS from import file (GCP manages these).
BIND / RFC 1035 Direct zone file generation possible: sort by Zone, write $ORIGIN header, emit each row as Name TTL IN Type RData. SOA must be first record per zone.
